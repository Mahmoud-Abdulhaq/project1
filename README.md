# Project 1 — About Me

A fresh, modern personal portfolio and profile showcase featuring **5 distinct spots to place in info**, with direct in-app customization, live preview, and persistent local storage.

## 5 Info Spots
1. **Spot 1: Bio & Identity** — Name, professional role, location, status badge ("Open to new opportunities"), personal story/bio narrative, email, and social links.
2. **Spot 2: Skills & Tech Stack** — Categorized technical competencies (Frontend, Backend, Tools) with interactive tags.
3. **Spot 3: Experience & Milestones** — Chronological journey of career positions, milestones, and education.
4. **Spot 4: Featured Creations & Projects** — Portfolio highlights with tags, summary descriptions, and direct URLs.
5. **Spot 5: Interests, Philosophy & Quick Facts** — Guiding principles, quote with author, and customizable quick-fact chips (tools, workflow, reading, hobbies).

## Key Features
- **Direct Spot Editing**: Click "Edit Spot" on any card or select a spot tab to quickly update and customize the content.
- **Persistent Local Storage**: Any customized information across all 5 spots is automatically saved and remembered.
- **Export & Share**: Export your complete profile as formatted Markdown (`.md`) or structured JSON (`.json`) with one-click copy.
- **Quick Jump Navigation**: Jump effortlessly between spots using the sticky top navigation or overview bar.
- **Reset Defaults**: Instantly restore default template content at any time.

## Tech Stack
- **Framework**: React 18 + Vite 6 + TypeScript
- **Styling**: Tailwind CSS with warm stone neutral aesthetic
- **Icons**: Lucide React
